# Flappy Bird Clone

A simple web-based game inspired by the classic Flappy Bird, built purely with HTML, CSS, and vanilla JavaScript.

## Features:

* Classic Flappy Bird gameplay mechanic (tap/click/spacebar to flap).
* Randomly generated pipe obstacles with increasing difficulty (pipes generate slightly faster as score increases).
* Score tracking during gameplay.
* High score saving: Your best score is saved locally in your browser.
* Responsive canvas: The game area adjusts to fit different screen sizes.
* Simple, clean visuals using HTML Canvas.
* Game over screen with score display and restart option.
* Built with vanilla HTML, CSS, and JavaScript (no external game libraries).

## Usage:

1.  Clone this repository or download the files (`index.html`, `style.css`, `script.js`).
2.  Ensure all three files are in the same directory.
3.  Open the `index.html` file in a modern web browser (like Chrome, Firefox, Safari, or Edge).

That's it! The game should start, displaying the initial screen.

## Technologies Used:

* **HTML:** Structure of the web page (Canvas, score display).
* **CSS:** Styling for the page layout, canvas, score display, and game over message.
* **JavaScript (Vanilla):** Game logic, physics (gravity, flap), drawing on Canvas, collision detection, scoring, high score saving (`localStorage`), and event handling.
